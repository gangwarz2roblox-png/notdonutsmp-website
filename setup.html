Setup

From download to ClickGUI.

Three steps, no launcher to install, no config to edit.

Get the jar

Sign in, open your dashboard and press Download. Your licence is already included — keep the file private.

Install Fabric

Use the supported Fabric profile and keep Fabric API in the same mods folder.

Drop & launch

Move the jar into .minecraft/mods, start the game and press Right Shift.

Find the folderPress Win + R, paste %appdata%\.minecraft and open mods.
Open the menuPress Right Shift after Minecraft has started.
Changing PCLifetime licences can unlink the old computer from Machine once every three months. Monthly licences do not include a hardware-ID reset.
Troubleshooting
If the game closes, check your licence and linked machine. If the client does not load, check Fabric API and your Fabric profile. For anything else, attach latest.log to a dashboard report.
